# 🐧 Command Line vs Non-Command Line

## 🎯 Concept

### 🟢 Command Line (Active Line)

**Definition:**
The command line (also called active line) is where the user **types and executes commands** in the terminal.

👉 Example:

```bash
ls
pwd
cd /home
```

✔️ These commands perform actions immediately.

---

### ⚪ Non-Command Line (Inactive Line)

**Definition:**
Non-command lines are lines that **do not execute anything**, such as:

* Comments
* Descriptions
* Output text

👉 Example:

```bash
# This is a comment (inactive line)
```

✔️ Used for explanation, not execution.

---

## 🧠 Key Difference

| Type             | Meaning           |
| ---------------- | ----------------- |
| Command Line     | Executes commands |
| Non-Command Line | Does not execute  |

---

## 💡 Example

```bash
# This is inactive (comment)
ls -l   # This is active (command)
```
